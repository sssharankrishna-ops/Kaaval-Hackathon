KEY DECISIONS IN THIS PLAN
═════════════════════════════════════════════════════════════════════════════

1. WHY Python 3.11?
   • PyTorch officially supports: 3.8, 3.9, 3.10, 3.11, 3.12
   • Python 3.13 is TOO NEW (not supported yet)
   • Python 3.11 is stable, widely compatible
   
2. WHY CUDA 12.1 (not 13.0)?
   • PyTorch best optimized for CUDA 12.1
   • CUDA 12.1 drivers work with CUDA 13.0 Toolkit
   • Maximum compatibility and stability
   
3. WHY conda (not pip)?
   • Faster: Uses cached packages locally
   • Reliable: Better dependency resolution
   • Stable: CUDA integration handled automatically
   • PyTorch provides conda as primary distribution method
   
4. WHY skip basicsr?
   • Has build issues (version conflicts)
   • Not critical for core face recognition
   • GFPGAN works without it for face restoration
   • Can be added later if needed

COMMON ISSUES & SOLUTIONS
═════════════════════════════════════════════════════════════════════════════

Issue: "conda: command not found"
Solution: Restart terminal or add Anaconda to PATH

Issue: Port 8000 already in use
Solution: 
  taskkill /FI "WINDOWTITLE eq *start_server.py*" /T /F
  Then restart

Issue: PyTorch still showing CUDA: False
Solution:
  • Verify: python -c "import torch; print(torch.__version__)"
  • Should contain "+cu121"
  • If not, uninstall and reinstall with conda

Issue: "No module named 'X'"
Solution:
  • Ensure conda environment is activated
  • pip install <package_name> -q

Issue: GPU Memory 0 MB / GPU Util 0%
Solution:
  • Models loading to CPU instead of GPU
  • Check ONNX Runtime GPU provider availability
  • May need to update NVIDIA drivers
