```python
    props = torch.cuda.get_device_properties(0)
    print(f"   Total Memory: {props.total_memory / 1e9:.1f} GB")
    print(f"   Capability: {torch.cuda.get_device_capability(0)}")
    print("   ✅ PyTorch GPU ENABLED")
else:
    print("   ❌ PyTorch CPU only")

# ONNX Runtime
print("\n2. ONNX Runtime:")
print(f"   Version: {ort.__version__}")
providers = ort.get_available_providers()
print(f"   Available Providers: {', '.join(providers)}")
if 'CUDAExecutionProvider' in providers:
    print("   ✅ ONNX Runtime GPU ENABLED")
else:
    print("   ⚠️  ONNX Runtime CPU only")

print("\n" + "="*70)
```

TROUBLESHOOTING REFERENCE
═════════════════════════════════════════════════════════════════════════════

If PyTorch install fails:
  → Check conda channels: conda config --show channels
  → Try: conda install pytorch torchvision pytorch-cuda=12.1 -c pytorch -c nvidia --no-deps -y

If CUDA detection fails (torch.cuda.is_available() = False):
  → Driver issue: nvidia-smi should work
  → PyTorch build issue: Reinstall with explicit CUDA version
  → Fallback: Use CPU mode (slower but functional)

If network timeouts:
  → Use conda instead of pip
  → Check internet connection
  → Use local package mirrors if available

If "ModuleNotFoundError":
  → Ensure conda environment activated
  → Run: pip install <package_name> -q

If port 8000 already in use:
  → Kill process: taskkill /FI "WINDOWTITLE eq *start_server.py*" /T /F
  → Or modify port in backend/app/main.py

If camera shows "waiting for camera":
  → Check camera module API: GET http://localhost:8000/api/camera/health
  → Verify USB camera connected (if using external)
  → Check logs for initialization errors
